# KefirGram

Android-клиент Telegram на основе открытых исходников **exteraGram**. Направление интерфейса: мобильный Discord и визуальный стиль Аурелии.

## Что уже добавлено

- Кнопка **А** в редакторе: одно нажатие подчеркивает даты и выделяет имена из словаря жирным. Удержание открывает настройки
- Форматирование применяется к черновику. Отправка остается отдельным действием
- Поддерживаются `18 марта 2049 года`, `15.08.2050`, `12/11/2060`, `2057-06-28`, отдельные годы и диапазоны лет
- Проверяется реальность календарной даты. Ссылки, адреса почты, упоминания, хештеги и код пропускаются
- Используются обычные Telegram-форматы текста. Уже заданные стили сохраняются и объединяются
- Локальный редактируемый словарь имен с падежными формами. Никаких запросов к нейросети или отправки черновика на сервер для форматирования
- Пункт **KefirGram** в боковом меню: тема и словарь
- Темная тема с акцентом `#A9F38F`, оригинальный значок моста для адаптивной иконки Android
- Отдельный пакет `com.kefirgram.messenger`. Проверка обновлений по умолчанию отключена; ручная проверка направлена в этот репозиторий

## Текущий этап

Это первая кодовая основа, **не готовый Discord-интерфейс**. Лента без пузырей, пространства вместо папок и переработанный профиль чата еще не реализованы. Нативный интерфейс пока сохраняет устройство exteraGram.

Полная Android-сборка и работа на устройстве еще не проверены. Публичная база exteraGram содержит версию 9.6.6; ее репозиторий архивирован. Это не исходники современной версии приложения из канала.

## Проверки

```sh
bash tools/test-aurelia.sh
```

Нужен JDK 17. Те же проверки запускаются в GitHub Actions. Они проверяют распознавание текста и XML-ресурсы; это не проверка сборки APK или поведения Android-редактора.

## Android-сборка

Оригинальные указания: [README.upstream.md](README.upstream.md). Потребуются Android SDK 33, Build Tools 33.0.1, NDK 21.4.7075529, CMake 3.10.2, собственные Telegram API ID/hash и собственный ключ подписи.

Создай локальный `API_KEYS` по образцу upstream README. Не добавляй его в Git. Замени `TMessagesProj/google-services.json` конфигурацией своего приложения и используй свой keystore вместо опубликованного upstream-файла.

```sh
./gradlew assembleAfatRelease
```
